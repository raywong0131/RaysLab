## 执行设计

1. 启动前核对源文件散列、几何、k=0、频率和模态映射；检查进程、COMSOL PATH、license，再只读加载保存模型。
2. 在同一批 34816 个面积分节点读取复 Ey、Hz，以及直接导数和 Lagrange 重建阶数 1/2/3 的 x 导数。
3. 使用 h=2、1、0.5 nm 的中心差分独立计算 Hz 导数。仅使用位移线段保持同一材料且未越出晶胞的节点；报告有效面积比例，Ey 对照也使用完全相同的节点和权重。
4. 增加穿过 A/B 孔的两条截线，以及孔边两侧的偏移探针，定位误差。保留复数；实部图采用唯一公共相位，不逐方法重新归一化。
5. 分别报告空气、介质、界面附近（5 nm 内）的加权 L2 残差及复积分。分区积分均除以完整晶胞面积，便于核对相加。直接导数为诊断项，不把异常零值当物理结论。
6. 每个原始模态和既有 py 组合独立比较。重新提取的 py 电场必须复现旧缓存；如不一致即停止，不继续解释。
7. 保存复场缓存、方法/区域汇总、计算身份和散列、诊断图及报告。结束检查原始文件未改变，释放本任务模型。

## 判读边界

- 本阶段优先判断插值、导数重建、界面取值与复模态组合是否造成差异；不预设任何方法必然正确。
- 差分避开材料界面但未识别所有有限元内部单元面，步长变化用于暴露这种敏感性。
- 三维中心平面与二维场近似一致暂作为工作假设；不能凭此要求两种表达数值严格相等。残差在多方法之间稳定，才说明单纯更换导数方法不足以解释差异。
- 同一已保存 mesh 上的阶数/步长检验不是网格收敛；不自动接受 S29–S31 的定量有效性。
