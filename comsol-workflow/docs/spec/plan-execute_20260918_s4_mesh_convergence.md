# S4 网格收敛：固定几何重新计算 Γ 点

## 授权、范围与目标

用户于 2026-09-18 明确要求“加密网格重新计算，验证网格的收敛性”。本轮保持已有三维半薄膜模型、材料、边界条件、Γ 点和本征求解设置不变，只改变网格。几何固定 b=245 nm、η=0.95、ζ=1、a=820 nm、H=200 nm。不是严格二维模型的新建，也不做 k 或几何扫描。

初始计划以保存的 mesh 5 解为基准，新增 mesh 4、3、2 三档求解；记录实际网格单元数和顶点数，不能只凭编号判断加密。COMSOL 官方定义：5 为默认，4/3/2/1 依次加密。实际发现局部尺寸约束保持不变，因此最终有效序列是对现有尺寸约束进行 h/h0=1、1/2、1/4、1/8 的缩放，详见执行记录。

用户 py 对应内部 px，即 Hz 对 x 奇、对 y 偶。每档先用与基准 p 子空间的场重叠识别两个 p 模式，再复用既有双模对称性分解；不把单个数值本征模的旋转当作网格误差。每个原始复频率保留，转换磁场后才组合。

## 实施与数值检查

1. 先核对源散列、参数与 Γ 身份、原本征频率，检查运行进程、PATH、许可证；保存本轮完整参数及来源记录。
2. 对 mesh 5 不求解，仅按新网格同样的方法提取作为基准。新网格逐档串行计算，不并行争用 COMSOL。
3. p 子空间匹配使用固定位置的复 Hz；训练点进行常数复系数组合，独立面积分点核验镜像误差。所有档使用相同的 Hz RMS 归一化和相位参考；额外记录对基准的复场重叠。
4. 主比较为 z=0 的直接 Ey 面积平均、1/ε 加权 Hz 导数平均、18 条孔边求和。空间 ε 每个节点分别赋值，不能用平均 ε 替代。复数实部、虚部均保留。
5. 同一几何积分节点用于跨网格局部残差；再做一档更密的面积/边界求积以及原生积分阶数检查，区分求积误差和有限元网格误差。保持逐模式频率，不改变导数重建规则。
6. 记录各档频率、p-pair 分裂、对称性残差、实际单元数、三种复积分、梯度对电场的局部 L2 残差和空气/介质分区。保存逐边贡献，避免只看净和。
7. 连续细网格变化使用完整复差及相对尺度；近相消时同时给绝对变化。以相邻细网格积分变化小于 1%、频率变化小于 1e-4 作为本轮操作性判断阈值，并要求求积变化更小；不把这些阈值宣称为普适精度保证。
8. 如果 mesh 2 仍未收敛，如实报告，不自动把趋势外推到“验证成功”，不自动启动其他物理模型。

聚焦测试覆盖 p 子空间匹配对任意双模旋转的不变性、复数收敛差、逐模态频率和分区残差；导入与测试不得启动 COMSOL。执行 py_compile、git diff --check，结果 PNG 实图和数据散列检查。
