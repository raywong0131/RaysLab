## 方法与边界

- 建立完整文件清单，区分回归验证、研究算法、计算入口、数据/来源记录、缓存与生成产物。
- 检查正式代码、测试、配置、文档及可见运行进程的引用；按具体功能比较，不仅依名称判重。
- 回归检查有维护价值；不因其不被生产导入而删除。独有研究代码、真实结果、来源身份和
  存在动态/外部依赖不确定性的内容先保留，记录缺少的判断依据。
- 删除前记录路径、大小、SHA256、原因、替代所有者和影响；对源码保留任务级恢复资料。
  Windows 删除使用原生 PowerShell LiteralPath；验证解析后的目标仅在本仓库 tmp/tests 内，
  不追踪目录链接，不跨 shell 拼接删除命令。
- 不改共享参数、正式科学算法、真实结果，不运行 COMSOL，不操作兄弟项目或根 .archives，
  不 commit/push，保留已有未提交修改。旧 archive_manifest 保留历史身份；另记本轮删除清单。
