# Ey、Hz导数与边界求和的双高度统一比较
用户要求比较当前30个ζ点、z=0及100 nm的Ey面积分、Hz偏导、边界求和。沿用η=0.96、b=245 nm、mesh=5、Γ点用户py、每边128点积分和表面Hz RMS=1 A/m相位/幅度归一化。只读取现有MPH，不建网格、不求解、不保存源模型。

定义A=∫Ey dS；D=-i/(ωε0)∫(∂xHz)/εr dS；B=i/(ωε0)(1/εair-1/εslab)Σ∮nxHz dl。统一单位V·m；裸导数积分及裸边界积分单位A，另存CSV。各混合模分量保留自己的复频率，先换算再按原系数求和。

Hz为矢量有限元导出场，沿用已验证d(laginterp(2,Hz),x)；同时导出∂zHx，得到Z=i/(ωε0)∫(∂zHx)/εr dS。记录外边界O=-i/(ωε0)∮outer nxHz/εr dl。连续场关系是A=D+Z、D=B+O；不预设mesh5数值结果满足。面积使用实际面与明确板层侧、原生阶数4/8，并复核直接Ey与前次数据一致。线积分使用前次定义的采样，不改变孔界面取值规则。

输出至原扫描任务下Ey_Hz_boundary_comparison。主图2×2：上/下z=0/100 nm，左/右实/虚部，每幅A、D、B。附图比较A、D+Z、B+O+Z，供解释遗漏项及数值误差；保留逐面逐模及逐边数据、原始Hz和复数汇总、核验记录、中文说明。仅真实点与直线连接。

验证复用频率/网格/模式Hz，z100边界与既有128点导出复现，面积与z坐标、4/8阶稳定性、逐模复频率换算测试、完整60组数据、源哈希不变和实际PNG。
