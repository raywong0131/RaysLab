# mesh5 cladding p2/d2 快速对齐扫描

日期：2026-07-29

## 实施前方案概述

### 目标

固定 cavity 为 `cav(245-0.960-1.156)`，保持 COMSOL 自动 mesh size 5，
从 `clad(242-0.980-0.930)` 出发寻找新的 cladding 参数。首要目标是使
cladding `p2@Gamma` 与 cavity `p2@Gamma` 对齐；cavity `d1@Gamma` 与
cladding `d2@Gamma` 的频差只作为软约束。

### 范围与约束

- 只计算 Gamma 点，不运行完整能带、Q-k 拟合、finite、Fourier 或 far-field。
- 仅对主程序选模频窗 `185--205 THz` 内的解执行有效性检查、模式成分和 Hz 场
  导出；频窗外解保留频率行但不做场后处理，以缩短每个候选耗时。
- 参数调整顺序固定为 `zeta -> eta -> b0`，最后只在联合最优点附近复核 zeta。
- cavity 参数、mesh5 和 unit-cell eigensolver 基准 `c_const/1.55[um]` 固定不变。
- 扫描任务显式求解 12 个本征模，以覆盖当前搜索基准下的两条 p 模和两条 d 模；
  不改动主程序中用户正在调整的 `EIGENMODE_COUNT`。
- 主对齐容差设为 `0.02 THz`。未进入容差时按 p2 误差排序；进入容差后先按
  d1/d2 软约束误差、再按 p2 误差排序。
- 不改写 `scripts/parameter.json`，新参数只写入任务输出和总结文件。
- 不覆盖或删除既有计算结果；候选按参数键缓存，可中断续算。

### 搜索策略

1. 独立计算并缓存固定 cavity 的 Gamma 模式与 `p2/d1` 基准。
2. 计算起点 `clad(242-0.980-0.930)`。
3. zeta 阶段：先计算起点两侧 `+/-0.004`，沿改善方向继续，步长 `0.004`，
   硬边界 `[0.890, 0.970]`；随后以 `0.001` 沿改善方向细化至首次恶化。
4. eta 阶段：固定已选 zeta，以 `0.004` 探测和推进，边界 `[0.940, 0.999]`，
   随后以 `0.001` 沿改善方向细化至首次恶化。
5. b0 阶段：固定已选 zeta/eta，以 `0.5 nm` 探测和推进，边界
   `[238.0, 246.0] nm`，随后以 `0.1 nm` 沿改善方向细化至首次恶化。
6. 在联合最优点对 `zeta +/- 0.001` 做一次复核，并按同一主目标/软约束规则
   选出最终参数。每一坐标方向最多连续推进 10 步，避免失控扫描。

### 数据流与输出

```text
固定 cavity 参数 + 起始 cladding 参数 + mesh5
  -> 复用 run_unit_cell_band 的几何、Gamma 求解和模式成分识别
  -> select_gamma_bands 得到 p1/p2/d1/d2
  -> 分阶段坐标扫描与参数键缓存
  -> scan_summary.csv + best_parameters.json + 每候选 config/场数据
```

输出位于允许的一级目录 `scripts/.out/unit_cell_band/` 下，任务目录名称包含固定
cavity、起点与 mesh5，不与既有正式结果冲突。

### 兼容与安全策略

- 新增独立 `run_sweep` 入口，不改变四个主入口的默认行为。
- 启动前打印 cavity、起点、范围、mesh、本征模数量、求解基准、输出目录与首批
  候选；提供 `--dry-run` 仅执行配置核对。
- 若 cavity 或候选未识别出两个有效 p 模和两个有效 d 模，立即记录失败并停止该
  坐标搜索，不以错误 mode index 继续优化。
- 若本机已有 COMSOL 任务，等待其结束，不并发争用 license 或内存，也不终止
  既有任务。

### 验证计划

- 聚焦单元测试覆盖模式标签目标、软约束排序、zeta/eta/b0 顺序、候选去重和边界。
- 对新增脚本运行 `py_compile`。
- 运行相关聚焦 pytest 和 `git diff --check`。
- 正式启动前执行 `--dry-run` 并人工核对输出。
- 正式运行后核对 cavity 参考、起点、每阶段最优、最终 CSV/JSON 和候选缓存。

### 回滚方案

- 新脚本和测试可独立移除，不影响现有主流程与扫描器。
- 扫描结果全部位于独立任务目录；不需要恢复共享参数文件。
- 不清理任何既有结果。若扫描失败，保留已完成候选供修正后续算。

- 固定 cavity 参考：
  - `p2@Gamma = 198.38683823113482 THz`

- 起点 `clad(242.0-0.980-0.930)`：
  - `p2@Gamma = 197.93875907646753 THz`，主误差 `0.44807915466728 THz`
  - `d2@Gamma = 200.74541852041344 THz`，软误差 `0.28394946179344 THz`
- 最优 `clad(242.0-0.986-0.917)`：
  - `p2@Gamma = 198.38970392155022 THz`，有符号误差
    `+0.00286569041543 THz`
  - `d2@Gamma = 200.44658371520586 THz`，相对 cavity d1 的有符号误差
    `-0.01488534341414 THz`
  - p2 与 d1/d2 误差均小于 `0.02 THz`；相对起点分别下降约 `99.36%` 与
    `94.76%`。
- 最终一次确定性遍历包含 22 个候选；包括首轮中断前缓存和后续补充细点在内，
  任务目录共有 28 个完整候选，全部具有 summary/config，没有残留不完整候选。
- 最优点在选模频窗内具有两个 p-dominant 和两个 d-dominant 有效模式；最优 p2
  的 `p_weight=0.995725`，最优 d2 的 `d_weight=0.999022`。
