# S31 面积—边界积分独立验证方案

状态：已完成已有数据可视化及 A 阶段现有 MPH 后处理核验，修正厚度导数提取；B 阶段新增求解未启动，S31 尚未得到验证。

## 目标和命名

验证同一 Γ 点、本征模式、z=0 nm 截面上的两种独立复数积分是否在数值加密后相符。用户命名 py 对应 Ey，px 对应 Ex；内部模式标签及数据字段不改。

对 py 定义：

- A_y = (1/S) ∫Ω Ey dS：直接对求解器的 Ey 作面积积分。
- B_y = KΓ Σe ∫e Hz nx dl：独立对 Hz 作孔边界积分。
- KΓ = i/(ω ε0 S) · (1/εair − 1/εdiel)：由实际频率、相对介电常数和单胞面积计算，不是拟合参数。
- 检验目标 A_y = B_y。归一化 A_y/A_y=1 本身不是验证证据。

E/H 使用同一个原始解与同一个复数归一化因子；不得为使两侧吻合分别调相位、符号、幅值或 KΓ。使用复本征频率进行 Maxwell 恒等式校验；若论文使用实频率近似，另报其影响。边界法向当前取 dielectric→air，必须与论文 S30 的定义一致。

## 三维模型中的完整关系

在 exp(-iωt)、标量分片介电常数、当前法向约定下，直接从 Maxwell 方程得到：

A_y = B_y + O_y + Z_y，

O_y = -i/(ω ε0 S εdiel) ∮∂Ω Hz N_x dl，

Z_y = i/(ω ε0 S) ∫Ω [1/ε(x,y)] ∂z Hx dS。

该 O_y 写法要求晶胞外边界位于同一介质，需核对实际几何。S31 对当前截面成立，要求 O_y=0 且 Z_y=0 或在已量化精度内可忽略。Γ 点支持周期外边界抵消；z=0 的镜面对称不自动令 ∂zHx=0：Hx 为奇函数时 Hx(0)=0，而其导数可非零。

截图未包含 S30 的完整推导；须核对其二维/厚度积分等假设，不能把截面公式和厚度平均公式混用。若完整三维关系收敛而 Z_y 显著非零，应报告 S31 的适用范围，不能删除该项以制造一致性。

## 执行顺序与计算范围

### A. 现有 MPH 后处理排查，新增本征求解数 0

1. 检查同一个 mode、Γ 波矢、相位约定、复频率、SI 单位、ε=n²、积分区域和法向。面积包含单胞的介质及孔空气。COMSOL 读取仍执行进程、许可和模型身份检查。
2. 优先用 COMSOL 在 FEM 网格/材料子域上的面积与边界积分，作为独立基准；z=0 面显式选择 slab-side。与 Python 现有积分交叉比较。不得用边界结果反推出 Ey，再把它作为面积侧证据。
3. 对 Γ 点外边界逐对配对采样/积分，记录每对复数残差与 Hz 值差；核对 Floquet 配对、实际边界选择以及插值实体侧。
4. 在远离孔接口的点核验局部 Maxwell 残差 ∂zHx − ∂xHz + iωε0εEy，并用 Hx 在邻近 z 的差分独立核验厚度导数。z=0 采用与半膜对称性相容的单侧或镜像差分，验证步长收敛；不能把导出的 0 当作已验证的物理结论。
5. 在固定 FEM 解上分别加密面积积分与边积分，至少形成三个精度档；报告 A_y、B_y、O_y、Z_y 的复数值及各自变化。顶点避让、材料迹和 Gauss 节点策略明确记录，不用跨介质平滑掩盖跳变。

先使完整关系的残差得到解释，再判断删去 O_y、Z_y 后的 S31 是否成立。

### B. 按 A 的结果选择必要的模型计算，不自动启动

- 若瓶颈是已有解的 FEM 误差：在同一几何和同一 Γ 点补充两档更细网格，预计新增 2 次本征求解；此前 mesh4/3 准备文件代码身份已过期，必须重新准备，不能直接复用旧执行身份。
- 若 S31 依赖严格二维 TE 假设而三维补充项不小：另建满足推导假设的二维周期模型，用三档网格验证，预计 3 次 Γ 点求解。将“二维公式验证”和“三维薄膜近似适用性”分开报告，不替换现有三维结果。
- 多参数验证放在单点积分与网格收敛之后：首先选择非零净振幅点，然后接近相消点。参数与求解总数在实际执行前单独明确，不为本方案自动增加扫描。

## 误差、门槛与报告

- 绝对残差：r_abs=|A_y−B_y|（V/m）。
- 非零信号点相对残差：r_rel=|A_y−B_y|/max(|A_y|,|B_y|)，并报告幅值比和相位差。
- 完整关系残差：r_full=|A_y−B_y−O_y−Z_y|。
- 近零点：同时报告 r_abs、积分加密变化、网格变化和相消条件数；相位差及比值仅在信号可辨时使用。加密差仅是经验误差估计，不冒充严格误差上界或统计置信区间。
- 建议在非零点预设 1% 的相对一致性目标，并要求积分/网格变化明显更小，至少三个精度档支持稳定趋势；具体验收阈值在执行前固定，不能根据结果放宽。近零点要求两侧差异与独立误差估计相容，且随加密稳定减小。
- 必须同时解释 O_y 与 Z_y，才能判断 S31 本身。只证明完整三维式闭合不等于证明 S31；代码测试通过也不等于物理关系已验证。
