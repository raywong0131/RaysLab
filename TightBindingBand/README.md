# TightBindingBand

一个无需安装依赖的单页网页工具，用来计算基于六边形周期单元的紧束缚能带。

## 使用方式

1. 打开 `index.html`。
2. 在左侧六边形图上直接填写 6 个格点的 `on-site energy` 和各条连边的 `coupling`。
3. 点击“计算能带”，生成三维能带图 `(kx, ky, ω)`。

## 当前模型假设

- 单元内有 6 个格点，位于正六边形 6 个顶点。
- 蓝色实线为单元内部耦合。
- 红色虚线为跨单元周期耦合。
- 晶格矢量定义为：
  - `a1 = a(1, 0)`
  - `a2 = a(1/2, sqrt(3)/2)`
- 三条跨单元耦合的平移分别是：
  - `p01 -> (1, 0)`
  - `p23 -> (0, 1)`
  - `p45 -> (-1, 1)`

## 数值实现

- 浏览器端直接构造 `6 x 6` 的 Bloch 哈密顿量。
- 对复 Hermitian 矩阵做实对称扩维后，用 Jacobi 迭代求本征值。
- 将 6 条能带作为三维线框曲面绘制在 Canvas 上。

## 后续可扩展

如果你希望把周期连边也完全改成“自己画、自己指定平移向量”的通用版本，可以在这个基础上继续扩展。
